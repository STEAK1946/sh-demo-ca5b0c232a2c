Help

  

    
EmployeesManagers

    
Store Hub keeps track of what is on hand at the store. It never orders, sends or pays for anything by itself.


    
For employees

    
1. Sign in
    
      
  1. First time on this phone: type the store code and tap Set up phone. You only do this once per phone. Ask a manager for the code.
    2. 
      
  2. Every time after that: tap your name, then type your 4-digit PIN.
    3. 
      
  3. New here? Tap I’m new, type your name and pick a 4-digit PIN. A manager approves you once, in person.
    4. 
      
  4. Handing the phone to someone else? Tap your name at the top right, then Switch.
    5. 
    
5 wrong PINs locks your name. A manager can unlock it or reset your PIN.


    
2. Count a vendor
    
      
  1. On the Vendors tab, tap On hand on the vendor you’re counting.
    2. 
      
  2. For each item, tap the big + or − to change the number.
    3. 
      
  3. Easier to type it? Tap the On hand number box and type the amount.
    4. 
      
  4. None left on the shelf? Tap Out of stock.
    5. 
      
  5. Tick Not counted at the top to see only the items you haven’t counted yet.
    6. 
      
  6. The coloured edge on each item shows its status: green is OK, orange is below target, red is out, grey is not counted.
    7. 
      
  7. Back on the Vendors list, the badge shows progress, like 12/20 counted. It says ✓ Finished when every item is done.
    8. 
      
  8. When you’re done, tap SUBMIT COUNT at the bottom. Items you skipped stay as they were.
    9. 
    
Counts save as you go, so it’s OK to stop and come back.


    
3. Fix a count after submitting
    
      
  1. After you submit, the count locks.
    2. 
      
  2. Tap Request adjustment and say what needs changing (for example “Ricotta is 2 cases, not 1”).
    3. 
      
  3. A manager has to approve it. Once approved, the count reopens and you can fix it.
    4. 
    


    
4. Receive a delivery
    
      
  1. Open the Receive tab. Orders show up here once a manager marks them complete.
    2. 
      
  2. Tap Check delivery on the order that just came in.
    3. 
      
  3. Tick each item as it comes off the truck.
    4. 
      
  4. Short or damaged? Tap Short / damaged, type how many and add a short note.
    5. 
      
  5. Tap RECEIVED. Items you didn’t tick are treated as not received.
    6. 
    


    
5. Ask for more of something
    
      
  1. Open the Items tab and search for the item.
    2. 
      
  2. Tap Request more. It shows up on the Requests tab.
    3. 
      
  3. A manager marks it ordered.
    4. 
    


    
6. Chat and Tasks
    
      
  • Chat: messages go to everyone using Store Hub.
    • 
      
  • Tasks: jobs for the team. Tick the box when a job is done.
    • 
    


    
For managers

    
Manager buttons sit in red dashed MANAGER boxes and the People tab. They only show when a manager is signed in. Employees never see them.


    
1. Manager sign-in
    
      
  1. On the sign-in screen, tap Manager login.
    2. 
      
  2. Type your email and password, then tap Sign in.
    3. 
      
  3. No login yet? Tap Create a manager login. You need the manager code once.
    4. 
      
  4. Forgot it? Tap Forgot password to get a reset email.
    5. 
    


    
2. Review counts
    
      
  1. Open a vendor with On hand. After it’s submitted, tap Approve count, or Reopen count if it needs redoing.
    2. 
      
  2. Adjustment requests show at the top of the Vendors tab. Tap Approve – reopen count or Deny.
    3. 
      
  3. Set a target for each item on the count screen. Order amounts fill in from it.
    4. 
    


    
3. Order and PDF
    
      
  1. Tap Order summary on a vendor. Amounts are target − on hand; change any amount to override it.
    2. 
      
  2. Items with no target are listed separately. Order those by hand.
    3. 
      
  3. Tap Mark order complete. This locks the amounts and sends the order to the Receive tab.
    4. 
      
  4. Tap PDF / Print, then Print / Save as PDF or Download PDF. On iPhone, pinch out on the print preview (or tap Share) to save it.
    5. 
      
  5. You place the order with the vendor yourself. The app never sends it.
    6. 
    


    
4. After the delivery
    
      
  1. Once the delivery is checked in, tap Mark received & reset counts.
    2. 
      
  2. This sets on hand to 0 for that vendor’s items and starts a fresh count.
    3. 
    


    
5. People and vendors
    
      
  • People tab: approve new employees, unlock after 5 wrong PINs, reset a PIN, or turn someone off.
    • 
      
  • + Vendor and Edit vendor add or change vendors and their contacts.
    • 
      
  • Requests: mark each one ordered when it’s done.
